# Règles de confidentialité - AYNEHA Margey

## AYNEHA Margey ne collecte aucune donnée.

Pas de compte, pas de numéro de téléphone, pas de serveur, pas de publicité, pas de traceur. L'application n'a même pas l'autorisation d'accéder à Internet : tout reste sur ton téléphone.

## Ton identité

Au premier lancement, ton téléphone crée lui-même ton code unique, sans connexion. Seuls ton pseudo et ce code sont visibles par les personnes à qui tu les montres (code QR). Tu peux changer ton pseudo à tout moment.

## Tes messages

Les messages sont enregistrés uniquement sur ton téléphone et sur celui de ton correspondant. Les messages privés sont chiffrés de bout en bout : seul le destinataire peut les lire.

## Le relais (réseau maillé)

Chaque téléphone AYNEHA Margey relaie automatiquement les messages des autres pour faire vivre le réseau. Un message privé relayé reste chiffré : ton téléphone le transporte sans pouvoir le lire. Si tu désactives le Bluetooth, tu deviens indisponible jusqu'à sa réactivation.

## Les salons

Les messages d'un salon sont publics : tous les téléphones à portée du salon peuvent les lire. Ils sont effacés après la durée choisie, de 3 jours au minimum à 90 jours au maximum. Un salon accueille 500 personnes au maximum.

## Les groupes privés

On entre dans un groupe uniquement en scannant son code QR d'invitation : ne le montre qu'aux personnes invitées. Les messages du groupe sont chiffrés : seuls les membres peuvent les lire, les autres téléphones les relaient sans pouvoir les lire. Un groupe accueille 100 personnes au maximum. Les messages du groupe ne s'effacent jamais d'eux-mêmes ; seul l'effacement d'urgence ou la sortie du groupe les supprime de ton téléphone.

## Les autorisations

Bluetooth et appareils à proximité : trouver les téléphones proches, envoyer et relayer les messages. Wi-Fi (sans Internet) : liaison directe entre téléphones compatibles. Localisation : exigée par Android sur certains téléphones pour la recherche Bluetooth ; AYNEHA Margey n'enregistre ni n'envoie jamais ta position. Caméra : scanner un code QR, uniquement quand tu le demandes. Micro : messages vocaux, uniquement pendant l'enregistrement. Notifications : t'avertir d'un nouveau message.

## Partage en image

L'image d'un message est créée sur ton téléphone, seulement pour l'application que tu choisis. AYNEHA Margey ne la conserve pas et ne l'envoie nulle part ailleurs.

## Effacer tes données

Tu peux tout effacer d'un coup avec l'effacement d'urgence dans les Réglages. Tu peux aussi choisir l'effacement automatique des discussions privées. Désinstaller AYNEHA Margey supprime tout ce qu'elle contient.
